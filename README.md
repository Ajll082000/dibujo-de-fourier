# Dibujo de Fourier

Sube cualquier imagen (JPG, PNG, WEBP, SVG…) y mira cómo se redibuja con círculos giratorios de Fourier, de 2 a 8192 términos.

**Ver la web:** https://dibujo-de-fourier.vercel.app

También disponible en GitHub Pages: https://ajll082000.github.io/dibujo-de-fourier/

Diseño y desarrollo por Alejandro López.
